This is a Python-based Student Grade Management System that allows users to manage student records efficiently using both a command-line interface and a graphical user interface (GUI) built with Tkinter. The application supports adding, updating, deleting, and viewing student grades using a dictionary-based backend. The GUI provides a simple and interactive way for users to perform these operations with input fields and buttons, while the console version offers a menu-driven interface for command-line use. 
The project is ideal for Python beginners to learn core concepts such as functions, dictionaries, error handling, and GUI development.
